# OKR Planning and Review Prototype

Lightweight V1 prototype for quarterly OKR planning and weekly review.

## Run locally

```bash
npm run dev
```

Open `http://127.0.0.1:3000`.

Demo credentials:

- Email: `demo.manager@example.com`
- Password: `demo-password`

## Scope

This V1 includes demo authentication, seeded Q2 2026 OKR data, browser-local plan editing, a review dashboard with filters, weekly update API validation with duplicate-week conflict handling, and CSV export.

It intentionally excludes task management, AI generation, Slack/Jira/Linear sync, performance reviews, advanced scoring, and database-backed plan editing.
